# TissueTypes

«ИИ-ассистенты»-2026: Определение типа ткани по экспрессии генов (данные RNA-seq)
Пономарева Анна (1 курс, трек ИИ в естественно-научной сфере)

## Задача

Есть матрица экспрессии генов для образцов из пяти тканей. Нужно определить, какой тип ткани соответствует каждому номеру (1–5), и выделить маркерные гены.

Критерий готовности: файл `tissues_result.csv` с пятью определёнными типами тканей.

## Данные

Папка `data/` (в репозиторий не входит из-за размера, см. `.gitignore`):

- `counts_hidden.csv` — матрица экспрессии: строки — гены, столбцы — образцы
- `meta_tissues_hidden.csv` — номер ткани (1–5) для каждого образца

## Структура проекта

| Файл / папка | Назначение |
|---|---|
| `AGENTS.md` | инструкции для агента: контекст, правила, запреты, критерий готовности |
| `ontology.yaml` | онтология проекта (граф знаний) |
| `agent_loop.ipynb` | ноутбук с циклом работы агента |
| `results/` | результаты и графики (например, `tissue3.png`) |


## Прогресс
- Неделя 1: опробование агента на небольшой задаче (количество образцов на каждый тип ткани)
- Неделя 2: работа с AGENTS.md, перва попытка выполнить цель проекта
- Неделя 3: первый цикл агента, подсчёт образцов по типам тканей
- Неделя 4: онтология и граф проекта (`AGENTS.md`, `ontology.yaml`)
- Неделя 5: поиск литературы и внешние графы знаний (OpenAlex, Wikidata)
