# INDEX.md — где что лежит

- `AGENTS.md` — правила работы агента в проекте.
- `STATUS.md` — где работа сейчас; читать в начале сессии.
- `diary.md` — журнал проекта; только дописывается.
- `data/counts_hidden.csv` — таблица с каунтами после РНК-секвенирования. Столбцы - образцы (samples), строки - гены (genes).
- `data/meta_tissues_hidden.csv` — номера тканей (от 1 до 5) для каждого образца.
- `memory/L2.md` - сжатая статья, на которую опираться
- `paper/` — здесь будет текст готовой статьи.
- `src/ - папка для скриптов
- `results/` — результаты; каждый файл пишет один скрипт из `src/`. Все графики также сохраняются здесь в формате png. Графики должны быть кастомизированы и сохранены в хорошем качестве.
