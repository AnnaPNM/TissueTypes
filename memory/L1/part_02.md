## Методы и результаты RNA-seq пайплайнов (с. 4–6)

Главное утверждение: из 192 RNA-seq пайплайнов (комбинации тримминга, выравнивания, подсчёта и нормализации) лучшим по точности и аккуратности признан Trimmomatic + RUM + HTSeq Union + TMM (с. 6). Метод: точность оценивали по 107 housekeeping генам (HKg) через CoV = MAD/Median (с. 4), аккуратность — по 32 генам через qRT-PCR и корреляцию Пирсона r (с. 4); ранги суммировали, сравнения — Kruskal–Wallis с post-hoc Dunn и FDR Бенджамини–Хохберга (с. 4–5). Результат: наиболее точный — Salmon с TPM (с. 6); в топ-10 доминируют HTSeq Union и TMM (с. 6); тримминг не дал значимых различий (FDR > 0.05) (с. 6). Вывод: подсчёт и нормализация — критические шаги (с. 6).
