# Определить ткани для типов 2, 3, 4, 5

Запрос пользователя: «Результат по типу 1 принимаю. Теперь определи ткани для остальных зашифрованных типов (2, 3, 4, 5) тем же методом и запиши итог в results/tissues_result.csv. Результат проверь независимым пересчётом.»

Готово, когда: `results/tissues_result.csv` существует, содержит колонки `sample_id` и `tissue`, ровно 5 различных типов тканей, без пустых значений; ткани для типов 2, 3, 4, 5 определены тем же методом (маркерные гены + классификация) и подтверждены независимым пересчётом; `python3 src/check_result.py` возвращает 0.
Не входит: изменение исходных данных, определение ткани для уже принятого типа 1 (Skin).

## План
1. Определить ткани типов 2, 3, 4, 5 по маркерным генам (тем же методом)
2. Проверить независимым пересчётом (второй метод классификации)
3. Записать итог в results/tissues_result.csv и проверить через check_result.py

## Итог
Типы 2, 3, 4, 5 определены как **Lung, Brain, Blood, Kidney** (тип 1 = Skin уже принят). Независимый пересчёт (`src/verify_tissues.py`): SVM(RBF)+PCA 5-fold CV accuracy = 1.0000; эталонные маркеры повышены в своих типах — Lung 7/7, Brain 7/7, Blood 7/7, Kidney 8/8. Итог записан в `results/tissues_result.csv` (6047 образцов, колонки sample_id и tissue, ровно 5 типов). Проверено: `python3 src/check_result.py` → OK (exit 0). В графе созданы заметки типов 2-5, тканей Lung/Brain/Blood/Kidney, результата и метода SVM-пересчёта.
