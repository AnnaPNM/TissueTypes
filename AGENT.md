# AGENT.md — Типы тканей и экспрессия генов

Файл-договор с агентом. Агент читает его в начале каждой сессии.
Тот же договор у других агентов называется `AGENTS.md`, `CLAUDE.md`, `.cursorrules`.

## Цель проекта
Имеются данные по экспрессии генов (RNA-seq) в некоторых тканях человека (ткани зашифрованы). Необходимо по этим транскрипционным данным определить, какие ткани зашифрованы. Подробно описать каждый шаг и методы, с помощью которых будут сделаны выводы о выборе типа ткани.

## Данные и материалы
- `data/counts_hidden.csv` — таблица с каунтами после РНК-секвенирования. Столбцы - образцы (samples), строки - гены (genes).
- `data/meta_tissues_hidden.csv` — номера тканей (от 1 до 5) для каждого образца.
- `paper/` — здесь будет текст готовой статьи.
- Исходные данные не изменять; производные файлы — в отдельных папках.

## Как работать
- Код — в `src/`, запускать перед тем, как сообщать результат.
- Каждый вывод сопровождается способом его проверки.
- Сводки и заметки для следующих сессий — в `memory/`.

## Журнал
- После каждой задачи — запись в `diary.md`: дата, запрос, что сделано,
  результат, точка проверки, итог проверки. Старые записи не менять.
- Образец:
```markdown
## yyyy-mm-dd — <короткое название задачи>
- Запрос агенту: <текст запроса>
- Что сделал агент: <файлы, команды>
- Результат: <что получено>
- Точка проверки: <чем проверяли, независимо от агента>
- Итог проверки: принято / отклонено / принято с исправлением — <почему>
```
