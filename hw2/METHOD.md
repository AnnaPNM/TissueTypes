# METHOD.md — методика проверки конвейера определения типа ткани

Записана **до первого прогона**. Дата записи: 08.11.2026 20:00. Любое изменение порогов или
правила принятия после просмотра результатов указывается в отчёте и в таблице раздела 8.

## 1. Замысел

В проекте тип ткани определяется по RNA-seq каунтам (56 200 генов x 6 047 образцов) цепочкой
log2(CPM+1) -> 3 000 самых вариабельных генов -> PCA(50) -> классификатор. Если ошибиться в
одном звене (например, считать CPM по сумме гена, а не образца, потерять образцы при
разбиении на фолды, перепутать метки), классификатор всё равно может показать высокую
точность, а вывод «тип 3 = Brain» окажется ненадёжным. Верификатор должен заметить такую
ошибку, а не повторить её.

**Проверяемое утверждение:** предобработка и оценка качества в `src/pipeline.py` ведут себя
как положено (свойства П1–П8), данные соответствуют договору (С1–С7), а классификатор
различает типы лучше случая (отрицательный контроль, П9).

## 2. Постановка

- **Меняется:** seed (0–4): определяет разбиение на фолды, инициализацию PCA и перестановку
  меток в контроле; вариант: настоящие метки / перемешанные.
- **Фиксируется:** данные (раздел 3), log2(CPM+1), 3 000 генов, PCA(50), логистическая
  регрессия, 5-кратная стратифицированная CV, версии пакетов (`requirements.txt`).
- **Измеряется:** accuracy по объединённым предсказаниям 5-fold CV; пары «настоящие —
  перемешанные метки» с общим seed.

## 4. Договор о схеме данных

| № | Правило |
|---|---|
| С1 | каунты конечные, неотрицательные, целые |
| С2 | id генов и образцов уникальны и не пусты |
| С3 | у каждого образца сумма каунтов > 0 (иначе CPM не определён) |
| С4 | метки — целые 1…5, пропусков нет |
| С5 | множества образцов в каунтах и метаданных совпадают |
| С6 | представлены все пять типов; на полных данных размеры типов равны известным (раздел 3) |
| С7 | `tissues_result.csv`: есть `sample_id`, `tissue`, нет пустых, образцы не повторяются; каждому типу соответствует ровно одна ткань, разным типам — разные ткани |

## 5. Свойства конвейера (тесты на свойствах)

| № | Свойство | Довод |
|---|---|---|
| П1 | умножение каунтов образца на константу не меняет CPM | глубина секвенирования не должна влиять на нормированную экспрессию |
| П2 | после обратного преобразования CPM каждого образца даёт 1 000 000 | сохранение «массы» при нормировке |
| П3 | log2(CPM+1) лежит в [0; log2(1e6+1)], нулевой каунт даёт 0 | физические границы величины |
| П4 | перестановка образцов и генов не меняет значения и набор отобранных генов | порядок строк и столбцов не несёт информации |
| П5 | фолды — стратифицированное разбиение: каждый образец в test один раз, train и test не пересекаются, в каждом test все классы | отсутствие потери и утечки образцов |
| П6 | вероятности классов в [0; 1] и в сумме дают 1 | вероятностный выход |
| П7 | одинаковый seed — одинаковый результат | воспроизводимость |
| П8 | рост каунта гена в образце не уменьшает его CPM | монотонность |
| П9 | отрицательный контроль: на синтетике с известной структурой настоящие метки >= 0,95, перемешанные <= 0,55 | конвейер не «угадывает» метки по артефактам |

## 6. План: шаги глубины и условия перехода

| Шаг | Что запускается | Условие перехода |
|---|---|---|
| dry | `run_experiment.py --step dry`: тесты на фрагменте + один seed | тесты проходят; точность на настоящих метках >= 0,90 |
| smoke | `--step smoke`: фрагмент, 5 seed, правило принятия (раздел 7) | правило принятия выполнено |
| full | `--step full`: полные данные, 5 seed, договор С1–С7 на полных данных | то же правило, порог точности 0,99 |

К шагу full переходим только после smoke. Дерево подцелей — в отчёте.

## 7. Правило принятия (записано до прогона)

1. Все тесты `checks/` проходят (код 0): на фрагменте и на полных данных (`TISSUES_FULL=1`).
2. Повторы: seed 0, 1, 2, 3, 4 (заданы заранее); результат — не лучший повтор, а среднее и разброс.
3. Метрика: accuracy 5-fold стратифицированной CV; одно значение на пару (seed, вариант).
4. Базовая линия: те же seed и те же фолды, метки перемешаны (`default_rng(1000 + seed)`); сравнение парное: d = acc_настоящие − acc_перемешанные.
5. Практический порог δ = 0,20: принимаем, только если нижняя граница 95 %-ного t-интервала среднего d больше δ.
6. Точность на настоящих метках: среднее >= 0,99 на полных данных (ожидание из первого прогона проекта — 0,9998), >= 0,90 на фрагменте; средняя точность на перемешанных метках <= доля самого крупного класса + 0,10.
7. Основное сравнение одно, поправка на множественные сравнения не нужна; при добавлении сравнений применяется поправка Холма и это отмечается в отчёте.

## 9. Ограничения

- Отбор 3 000 генов по дисперсии выполняется на всех образцах до CV; метки в нём не используются, но это не вложенная валидация.
- Точность ~1,0 говорит о лёгкой отделимости типов, а не о правильности имён тканей: имена (Skin, Lung, Brain, Blood, Kidney) проверяются отдельно по маркерным генам, этот верификатор их не доказывает.
- Свойства П1–П8 проверены на синтетических данных; П9 — на синтетике. Данные не покрывают всех пограничных случаев реальных каунтов.
- Верификатор проверяет `src/pipeline.py`; совпадение с `src/tissues.py` обеспечивается тем, что `tissues.py` импортирует функции из `pipeline.py`.
- Фрагмент данных (100 образцов, 500 генов) мал: интервалы на нём шире.
