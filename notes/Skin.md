# Skin

Ткань человека — кожа. Определена для зашифрованного типа 1 по маркерным генам: кератины (KRT14, KRT1, KRT5, KRT10, KRT2, KRT15, KRT80), филаггрин (FLG, FLG2), лорикрин, десмосомные белки (DSC3, DSG1, PKP1, DSP), CASP14, DMKN, SBSN. Подтверждена независимым пересчётом (SVM + корреляция с эталонными генами).
